# Context

## Domain Terms

- Activity: canonical code/API term for a manager-owned focus that defines feedback questions and groups one or more sessions.
- Focus: user-facing name for an Activity.
- Event: canonical code/API term for a scheduled occurrence of an Activity.
- NotificationHistory: manager-facing record of feedback notifications and unseen counts.
- ParticipantEvent: participant-facing representation of an Event.
- Session: user-facing name for an Event.

Avoid using "event" in visible copy for the manager-facing session detail flow.
