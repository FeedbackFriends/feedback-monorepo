---
name: lg-commit-and-push
description: Commit or push LetsGrow changes only when requested.
---

1. Review status/diff; stage only intended changes.
2. Make small, coherent commits with clear messages.
3. Push only if requested: user-named branch, otherwise current branch. Ask if detached.

Leave unrelated work untouched. No branch switching or history rewriting unless requested. Report commits, push result, and relevant checks.
